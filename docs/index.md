# Fantasm documentation

Fantasm is a consolidated suite of tools for annotated disassembly of 6502
code. Documentation will grow alongside the codebase.

## Sections (planned)

- **CLI reference** — every `fantasm` sub-command, its options, and example
  output in each `--as` format.
- **API reference** — the `fantasm.api` package, organised by topic (labels,
  comments, control flow, audit, ...).
- **Project configuration** — the schema and conventions for `fantasm.toml`.
- **Migration notes** — guidance for sibling repositories (acorn-nfs,
  acorn-adfs, acorn-econet-bridge, acorn-6502-tube-client) when they switch
  from their bundled `disasm_tools` to a fantasm dependency.

For a quick start see the top-level `README.md`.
